# Vídeo de demostración

El vídeo es una evidencia complementaria. No se considera obligatorio mientras el mecanismo de entrega no lo confirme expresamente.

## Contenido público versionado

- Este README define límites y preparación.
- [storyboard.md](storyboard.md) describe el recorrido previsto.
- El vídeo final, proyectos de edición, tomas y logs de grabación no se guardan en Git.

## Reglas de privacidad

- Usar datos preparados para demostración y una sesión controlada.
- No mostrar ni narrar contraseñas, tokens, correos reales, Keychain, rutas locales, notificaciones personales o configuración privada.
- Revisar encuadre, audio, barra de estado, consola y fondos antes de publicar.
- No almacenar una cuenta o credencial de demo en el repositorio, issues, guion o fixtures.

## Evidencia

El vídeo no sustituye build, tests, auditorías o gate DocC. Toda afirmación técnica debe corresponder a evidencia registrada en [Progress](../Progress.md). Un flujo pendiente se marca como pendiente; no se simula como terminado.

## Grabación

Preparar datos locales y un fallback sin red para que una indisponibilidad del backend no invalide toda la narración. El material privado de preparación vive fuera del repositorio.
